# Soft Fork

**Category:** Technology

## Plain English

Na upgrade to Bitcoin rules wey dey backwards-compatible, meaning say old nodes fit still dey inside the network even if dem never update.

## Analogy

Think am like market wey dey accept both old and new naira notes before. Then government come introduce new rule say: only new notes go dey valid for big purchases. People wey dey use old notes fit still dey buy small things, dem never chase dem comot. But as time dey go, most people go switch to new notes because e better pass. Soft fork dey work the same way: dem add new rules, but nobody dey force anybody comot from network.

## In Context

Dem activate SegWit as soft fork for 2017.

Dem add new set of rules to Bitcoin without splitting the network or forcing everybody to update at the same time. Nodes wey never upgrade fit still send and receive transactions, them just no fit use the new features.

## Why It Matters

Bitcoin dey upgrade itself through soft forks without breaking into separate coins. Na so the network dey improve over time while everybody dey remain for the same chain. If the upgrade no be backwards-compatible, dem go call am hard fork and that one fit cause permanent split.
